# BusBus — транспорт онлайн без рекламы

Онлайн-карта общественного транспорта **Новосибирска** и **Красноярска**: где сейчас автобус, троллейбус, трамвай или маршрутка, через сколько минут он будет на нужной остановке.

- 🚌 Реальные данные официальных порталов: [map.nskgortrans.ru](https://map.nskgortrans.ru/) (МКУ «ЦУГАЭТ») и [mu-kgt.ru](https://mu-kgt.ru/informing/wap/marsh/) (МКУ «Красноярскгортранс»).
- 📱 Android-приложение (APK) и веб-версия / PWA с одним и тем же интерфейсом.
- 🧪 Демо-режим: полностью автономная симуляция движения — интерфейс можно смотреть без сети.
- 🚫 Никакой рекламы, аналитики и трекеров.

## Что умеет

| Возможность | Новосибирск | Красноярск |
| --- | --- | --- |
| Координаты машин на карте | ✅ GPS с источника | ➖ позиция по остановкам |
| Скорость и курс машины | ✅ | ➖ |
| Ближайшие остановки с прогнозом | ✅ | ✅ |
| Список маршрутов по типам транспорта | ✅ | ✅ |
| Табло остановки | ✅ (WAP-версия, cp1251) | ✅ |
| Темная карта, геолокация, избранное | ✅ | ✅ |

Красноярский портал не публикует GPS-координаты — только позицию машины «в очереди» между остановками
(«менее 370 метров до …»). BusBus показывает такие машины на линии маршрута в соответствующей точке и
помечает значком «≈ позиция», чтобы не выдавать приблизительное за точное.

## Структура репозитория

```
core/   общая библиотека: провайдеры данных, карта (Leaflet), экраны, тема
web/    веб-версия и PWA: сборка Vite, манифест, service worker, single-file бандл для APK
apk/    Android-обёртка (WebView + нативный HTTP-мост, без CORS-прокси)
ci/     артефакты CI: скриншоты интерфейса, APK
```

`core` не зависит от платформы: те же экраны открываются в браузере и в WebView Android.
Единственное отличие — HTTP-слой: в браузере это `fetch`, в APK — нативный мост.

## Быстрый старт (разработка)

```bash
cd core && npm install
cd ../web && npm install
npm run dev          # http://localhost:5173
```

Полезные команды:

```bash
cd core && npm run typecheck     # строгая проверка типов
cd web && npm run build          # PWA для GitHub Pages
cd web && npm run build:android  # single-file HTML → apk/app/src/main/assets/index.html
cd apk && gradle assembleDebug   # APK (нужен Android SDK)
```

## Android-приложение

Сборка APK уже настроена в GitHub Actions (`.github/workflows/android.yml`).
Свежий отладочный APK публикуется в ветку `ci/shots` (`ci/apk/busbus.apk`) и в артефакты workflow.

Почему нужен отдельный APK, если есть сайт: официальные порталы не отдают CORS-заголовки,
поэтому в обычном браузере живые данные получить нельзя. В приложении используется нативный
HTTP-мост (`JavascriptInterface`), который забирает данные без ограничений браузера — быстро и без прокси.

## Веб-версия и GitHub Pages

`npm run build` собирает PWA. Деплой — `.github/workflows/pages.yml`; чтобы он заработал,
включите GitHub Pages в настройках репозитория: **Settings → Pages → Source: GitHub Actions**.

Без публичного прокси живые данные в браузере не загрузятся (CORS), поэтому веб-версия стартует
в демо-режиме. В «Настройках» можно указать собственный прокси-шаблон вида
`https://ваш-прокси/?url={url}` — тогда в браузере тоже будут реальные автобусы.

## Источники данных и честность

* **Новосибирск** — публичные эндпоинты сайта ЦУГАЭТ: `listmarsh.php`, `markers.php`,
  `forecast.php`, `trasses.php`. Формат времени и кодировка разбираются в `core/src/transport/nsk.ts`.
* **Красноярск** — публичный JSON мобильной версии: `?m=<маршрут>&action=getMarshData`
  (`core/src/transport/krsk.ts`).
* Данные принадлежат операторам; приложение только отображает их и не связано с перевозчиками.
* Точность прогнозов зависит от источника. Позиция машины в Красноярске — расчётная.
